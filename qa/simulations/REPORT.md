## Unresolved edge cases (need Russ taste)

- **pr-merged**: Leaf collapses or vanishes while root grows — connection teardown timing
- **pr-draft-open**: Draft vs ready PR — same cable kind, different face; viz needs draft chrome without new kit id
- **ci-flaky**: startled emotion without lasting growth change — emotion-only flicker
- **dep-supply-chain-scare**: Dependency plant should look hostile without new weed propKind
- **mono-canopy-many-packages**: Five plants + four workspace links in one strip — overcrowding / label collision
- **cross-org-breaking-api**: Which plant 'owns' the warn face — provider or consumer habitat
- **cancelled-work**: Leaf demoted to stale + growth drop — teardown vs merge celebration
- **stage-rooftop-complete**: jump vs celebrate — both ok; recipe packs should pick one
- **multi-org-plus-mono**: workspace + remote mixed graph; mirrored loadingLeft face
- **ci-pass-mono-matrix**: Celebrate with many leaves — rooftop crowding with workspace links
- **Polyrepo multiple roots**: garden metaphor assumes one canopy — how loud should hub cables be?
- **Gate for approve vs deny**: same stage, opposite faces — need distinct barrier chrome?
- **Draft PR cable**: dashed/dim host chrome without new kit link kind?
- **Stale weed contrast**: growth 1 vs 5 enough, or need opacity/desaturate host rule?
- **Unbridged emotions** (`relieved`, `startled`, `sad`, `alert`): habitat-ok but no mark face — when to prefer face vs emotion?
- **growthUpdates teardown** after merge: vanish leaf instantly vs wilt animation?
