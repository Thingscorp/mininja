## The Apple of Terminal Buddies

Mininja aims to be **the Apple of Terminal Buddies** — a quality standard for how a terminal companion should feel:

| Pillar | What a stranger should feel |
|--------|-----------------------------|
| **Obsessive craft** | Every glyph, timing, and default is deliberate. |
| **Taste** | Restraint over ornament. The Unicode lockup *is* the premium mark — no redrawn substitute. |
| **Purity of default** | The stock kit feels right out of the box. |
| **Inevitable system** | mark → faces → scoot → scene snap together as one product, not a pile of demos. |
| **Loveable helper** | Warm, portable, people carry it into every host. |
| **Glanceable presence** | A peek tells you what matters; quiet warm idle is the default when nothing’s wrong. |

Quality metaphor only — never use the Apple logo. Discreet notice: [TRADEMARK.md](TRADEMARK.md).

## Rubber-duck companion (voice)

Mininja is a **desk companion** in the spirit of a rubber duck you keep nearby — plus a quiet glance at the developer’s world so tabs stay closed. It does **not** shout notifications like a status board. It changes **posture** (face, stage, plant silhouette). Text is optional chrome; the signal is presence.

Metaphors only — **not affiliated with** any rubber-duck brand, Bandai, Pebble, IFTTT, or Apple Inc.

## Terrarium for Devs (v1)

Mininja is a **terrarium for developers** — a small living world on the desk you remix like Lego. **v1 ship** is **pal + habitat strip** (Russ, 2026-09-26; same bar as “creature + habitat”). Mark-only is the ~60s on-ramp, not a complete v1. Do not ship recipes-first:

| Piece | What it is |
|-------|------------|
| **Glass box on the desk** | Console / bot surface — the window you look through |
| **Pal** | The Unicode mark — warm, **unnamed** agent presence in the glass (never Casque; no he/him) |
| **Habitat glass** | Stages, props, and **scene weather** as scenery chrome from [`kit/`](kit/) ([SCENERY.md](SCENERY.md)) |
| **Garden** | `repoBranch` plants — ambient repo / goal health ([GARDEN.md](GARDEN.md)) |
| **Craft bar** | *The Apple of Terminal Buddies* (quality metaphor only) — how carefully the pieces are cut |

**Pal** = product noun for the agent creature (human-driven buddy / coding agent / automation actor). Multiple pals may appear later, color-distinguished as a **modular host layer** — not a kit color catalog ([`GLANCE.md`](GLANCE.md)).

You remix the terrarium; you do not redraw the pal. Habitat is data. Scene weather is chrome on the strip — not external automation. Metaphors only — not affiliated with Apple Inc.

Recipes / IFTTT-style “weather from the outside world” are a **later plate** — design lives in [RECIPES.md](RECIPES.md), not required for first Mininja. That plate plugs into the **same** pal + habitat + garden bricks (they talk to each other); demotion ≠ disconnection. Packs filter what the duck notices ([`GLANCE.md`](GLANCE.md)).

## Still true

- **Lego modularity** — pieces snap; forks and overlays are encouraged
- **kit = data** — rules live in [`kit/`](kit/) JSON and are meant to be modified
- **Unix-small** — one job per module ([`adapters/`](adapters/), [`examples/`](examples/), optional [`console/`](console/) / [`bot/`](bot/)). **bot** = launcher over console, not a second brand UI; no phone required
- **Mascot / pal unnamed** — no personal name (never Casque); no he/him
- **Spelling: Mininja** — never “minija”
- **Recipe seams** — face · stage · action · emotion · growth as kit id strings; tone/`then.mood` = chrome only ([`NORTH-STAR.md`](NORTH-STAR.md))
- **No second dashboard** — glanceable posture; KPIs move growth via packs only; no digipet care framing
