# Brand positioning

## The Apple of Terminal Buddies

Mininja aims to be **the Apple of Terminal Buddies** — a quality standard for how a terminal companion should feel:

| Pillar | What a stranger should feel |
|--------|-----------------------------|
| **Obsessive craft** | Every glyph, timing, and default is deliberate. |
| **Taste** | Restraint over ornament. The Unicode lockup *is* the premium mark — no redrawn substitute. |
| **Purity of default** | The stock kit feels right out of the box. |
| **Inevitable system** | mark → faces → scoot → scene snap together as one product, not a pile of demos. |
| **Loveable helper** | Warm, portable, people carry it into every host. |

Quality metaphor only — never use the Apple logo. Discreet notice: [TRADEMARK.md](TRADEMARK.md).

## Still true

- **Lego modularity** — pieces snap; forks and overlays are encouraged
- **kit = data** — rules live in [`kit/`](kit/) JSON and are meant to be modified
- **Unix-small** — one job per module ([`adapters/`](adapters/), [`examples/`](examples/), optional [`console/`](console/) / [`bot/`](bot/))
- **Mascot unnamed** — no personal name; no he/him
- **Spelling: Mininja** — never “minija”
